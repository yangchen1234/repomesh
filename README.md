# RepoMesh

RepoMesh is a local-first compute node for codebase retrieval-augmented generation. It combines Tree-sitter symbol chunks, SQLite FTS5 lexical search, pluggable embeddings and vector stores, reciprocal-rank fusion, durable incremental indexing jobs, exact source-line citations, a browser dashboard, evaluation, and performance measurement.

The Windows single-node vertical slice is under active local verification. Complete setup, API, security, benchmark, and Mac control-plane handoff instructions are maintained in the accompanying documentation.
